# Sharkie

Ein 2D-Jump-and-Run/Action-Spiel, in dem du als Hai Sharkie durch die Tiefsee schwimmst, Münzen sammelst, Gegner bekämpfst und am Ende der Map den Endboss (Orca) besiegst.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Spielprinzip

- Du steuerst den Hai Sharkie durch das Level
- Sammle Münzen
- Kämpfe gegen Fische und Quallen
- Besiege am Ende der Map den Endboss

## Steuerung

| Taste       | Aktion       |
|-------------|--------------|
| ← → ↑ ↓     | Bewegung     |
| Leertaste   | Angriff      |
| D           | Bubble Angriff      |

## Installation / Starten

1. Repository klonen:
```bash
   git clone https://github.com/Louisjuc/sharkie.git
```
2. `index.html` im Browser öffnen – fertig, kein Build-Prozess nötig.
